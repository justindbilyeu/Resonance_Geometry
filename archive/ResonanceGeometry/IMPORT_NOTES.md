# ResonanceGeometry — not imported, on purpose

This directory was staged in 2025 for a `git subtree add` of
[justindbilyeu/ResonanceGeometry](https://github.com/justindbilyeu/ResonanceGeometry),
the origin repository. The import failed at the time on a proxy error and was
never retried.

**As of 2026-09-02 the decision is to leave it un-imported**, and this note
replaces the stale "staged for a future import" one.

That repository is the philosophical origin of this work — ten axioms, "form is
frozen resonance", "emotion is curvature", consciousness as a projection
operator. Its own first commit here says what happened next: this repository's
initial README, 2025-08-24, read in full

    # Resonance_Geometry
    Cleaned up ResGeo

So the origin material is genuinely the ancestor of everything in this
repository, and it deserves to stay findable. It does not belong *inside* a
repository whose front page now sorts claims by whether they are established,
open, or unsupported — the origin material is none of those, because it makes no
testable claims at all. Vendoring it here would blur exactly the line the README
was corrected to draw.

Provenance is preserved by the link, not by the copy.

One thing worth stating plainly, since the numerical work is sometimes assumed
to have come from there: **it did not.** There is no Hopf, no eigenvalue
analysis, no α-sweep and no 0.833 anywhere in the origin repository. The
non-Hopf result was produced in *this* repository between 2025-10-19 and
2025-10-24, and corrected here in `e40c842` on 2025-12-06.
